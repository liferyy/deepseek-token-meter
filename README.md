# DeepSeek 本机用量

为 Trae CN / VS Code 提供本地 DeepSeek API 代理、每日模型 Token 统计与人民币费用估算。

所有用量数据只保存在本机，不上传、不包含对话内容，也不需要把 DeepSeek API Key 交给插件保存。

## 功能

- **本地反向代理**：把 Trae 自定义模型的请求转发到你配置的上游地址（默认 `https://api.deepseek.com`），保留原有流式输出、工具调用和 API Key 认证。
- **Token 统计**：记录经过代理的模型请求，按自然日和模型拆分非缓存输入、缓存读取、缓存写入、输出与推理 Tokens。
- **人民币估算**：为每个模型配置当前单价，历史记录会按最新单价重新估算；未配置价格的模型仍统计 Token，并明确显示“未定价”。
- **用量面板**：近 10 分钟 / 1 小时 / 今日 / 一周 / 30 天 / 自定义日期趋势、模型筛选、缓存命中率、每日活跃热力图与最近请求。
- **透明提示**：成功、异常、取消、无 usage、部分 usage 和未定价请求分别计数，避免把“未知”当成“零消耗”。
- **每日 CSV、JSON 备份与导入**：导出按日和模型汇总的 CSV；备份不含 API Key；导入按记录 ID 去重，并保留当前单价。
- **多窗口共享**：同一编辑器安装实例共享一个本机代理进程；扩展不再轮询（例如窗口关闭）后，代理空闲十分钟自动退出，下次使用会自动拉起。

## 快速开始

### 1. 安装

要求 VS Code `1.85.0` 或更高版本（Trae CN 基于 VS Code，同样适用）。

从源码构建：

```bash
npm ci
npm run check
npm test
npm run package
```

然后在编辑器的扩展面板中选择“从 VSIX 安装”，安装生成的 `deepseek-token-meter-1.0.0.vsix`。

### 2. 启动本机代理

安装后代理默认随编辑器启动。也可以执行命令面板中的：

- `DeepSeek 本机用量：启动本地代理`
- `DeepSeek 本机用量：停止本地代理`
- `DeepSeek 本机用量：打开统计面板`

状态栏会显示今日 Token 总量和代理运行状态；点击状态栏可打开面板。

### 3. 在 Trae 中接入

打开统计面板的“接入设置”，按以下方式添加自定义模型：

| 字段 | 填写内容 |
| --- | --- |
| API 格式 | OpenAI Chat Completions 格式 |
| 基础地址 | `http://127.0.0.1:18765/v1` |
| 完整 URL | 关闭 |
| 模型 ID | DeepSeek 平台实际支持的模型 ID |
| API 密钥 | 你自己的 DeepSeek API Key |

如果开启“完整 URL”，请填写 `http://127.0.0.1:18765/v1/chat/completions`。

代理只把请求转发给上游，API Key 由你的客户端随请求发送，插件不会把它写入磁盘。连通性测试也是一次真实调用，会被计入用量。

### 4. 配置单价

在“模型定价”中为模型填写人民币 / 百万 Tokens 单价：

- 非缓存输入价格
- 输出价格
- 缓存读取价格
- 缓存写入价格

模型 ID 支持末尾 `*` 的系列匹配，例如 `deepseek-*`。优先匹配上游实际返回的模型 ID，其次匹配请求中填写的模型 ID，最后按最具体的通配符匹配。`0` 表示该项免费。

费用公式：

```text
费用 =（非缓存输入 × 输入单价 + 缓存读取 × 读取单价
      + 缓存写入 × 写入单价 + 输出 × 输出单价）÷ 1,000,000
```

这是按当前单价计算的估算值，不代表服务商的实际扣费账单。

## 统计口径

- 只统计请求经过本机代理的模型生成调用；`/v1/models` 查询不计入。
- 按请求开始时间和配置的时区（默认 `Asia/Shanghai`）归属自然日。
- DeepSeek 的 `prompt_tokens` 已包含缓存命中部分，`completion_tokens` 已包含推理 Tokens。插件会拆分缓存读取/写入，避免重复累计；推理 Tokens 只作为输出中的明细展示，不再额外相加。
- 成功、异常、取消分别统计。HTTP 错误、上游中断、客户端取消和缺少 usage 的请求都有独立标记。
- 没有收到 usage 的请求会记录为“用量未知”，不按 0 费用计入；中断请求可能只收到部分 usage。
- 支持解析 DeepSeek / OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 风格的 usage 字段，并对 gzip / deflate / br 响应解码后统计。

## 数据与隐私

数据目录由编辑器分配，可在面板“本地数据”中查看并打开，通常位于全局存储目录下的 `local-tools.deepseek-token-meter`：

```text
config.json          上游地址、时区、模型单价
events/YYYY-MM.jsonl 用量记录，每月一个文件
admin-token          本机管理接口令牌
```

- 用量记录只包含模型、时间、Token、状态、HTTP 状态、耗时和错误码，不保存 API Key、对话、提示词或响应正文。
- 代理仅监听 `127.0.0.1`，拒绝带 `Origin` 的浏览器请求和非本机 Host。
- 管理接口需要随机令牌；令牌文件以仅当前用户可读写的方式创建。
- 代理不会启动浏览器，也不会把端口暴露到局域网。
- 卸载插件不会自动删除历史用量；需要清理时可直接打开数据目录操作（建议先导出 JSON 备份）。

## 常见问题

**端口被占用 / 提示“已被其他程序占用”**

修改设置 `deepseekTokenMeter.port`，重新加载窗口后启动代理。不要与其他服务共用端口。

**Trae 返回 401 或提示填写 API Key**

代理不替你保存密钥。请在 Trae 的自定义模型配置中填写有效的 DeepSeek API Key。

**面板没有新数据**

确认代理正在运行、Trae 的基础地址指向 `http://127.0.0.1:18765/v1`、且没有开启“完整 URL”，然后发起一次模型对话。连通性测试也会计入用量。

**费用显示“未定价”或“—”**

在“模型定价”中为对应模型配置四项单价并保存。没有 usage 的请求无法估算费用，会显示为未知。

**流式请求没有 usage**

DeepSeek 官方接口通常会在流末尾返回 usage。如果使用兼容中转服务，可在设置中开启“为流式请求补充 `stream_options.include_usage`”。

**代理空闲后停止**

编辑器窗口关闭或扩展停止轮询后，代理在十分钟无请求时自动退出，这是正常行为；再次打开编辑器、面板或发起请求会自动拉起。

## 限制

- 只记录经过本机代理的请求。Trae 内置云端模型、其他电脑、直接在别处调用官方 API 的请求不会自动出现。
- 费用是估算，不替代服务商账单；单价需要手动维护。
- 仅面向本机单用户，不提供局域网共享、账号体系或云端同步。
- 代理支持常见的 OpenAI / Anthropic 兼容接口路径；其他接口会返回 404 提示。
