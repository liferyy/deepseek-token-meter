# DeepSeek 本机用量

为 Trae CN / VS Code 提供本地 DeepSeek API 代理、每日模型 Token 统计与人民币费用估算。

所有用量数据只保存在本机，不上传、不保存对话正文，也不需要把 DeepSeek API Key 交给插件保存。

## 功能

- **本地反向代理**：把 Trae 自定义模型的请求转发到你配置的上游地址（默认 `https://api.deepseek.com`），保留原有流式输出、工具调用和 API Key 认证。
- **Token 统计**：记录经过代理的模型请求，按自然日和模型拆分非缓存输入、缓存读取、缓存写入、输出与推理 Tokens。
- **峰谷计价**：为每个模型配置高峰单价，空闲时段自动按 50% 计算；按每条请求的开始时间判断峰谷，历史记录会按最新单价重新估算，未配置价格的模型仍统计 Token 并明确显示“未定价”。法定节假日与调休安排来自公开数据源，启动插件时自动刷新并缓存，窗口跨年不重启时也会补刷当年数据；多个编辑器窗口通过文件锁避免重复请求，也可在面板中手动切换为“只按周一至周五判断”的兜底规则。
- **用量面板**：近 10 分钟 / 1 小时 / 今日 / 一周 / 30 天 / 自定义日期趋势、模型筛选、缓存命中率、每日活跃热力图与最近请求；趋势图同时标注有请求时段的平均与中位数，最近请求支持分页浏览并显示标题或结构化摘要。代理写入新记录后主动推送更新（最多每 3 秒一次）；推送流断开时会自动刷新并退避重连，扩展只用轻量心跳保持代理存活，不再定时重算全年聚合。
- **透明提示**：成功、异常、取消、无 usage、部分 usage 和未定价请求分别计数，避免把“未知”当成“零消耗”。
- **每日 CSV**：导出按日和模型汇总的 CSV（含高峰 / 空闲费用拆分，跟随面板当前的时间范围与模型筛选），可用于报表与长期留档。
- **数据维护**：用量只保留最近 365 天，启动时自动删除过期记录并通过 SQLite 增量回收释放磁盘空间；面板提供需要输入确认的“清空数据”入口。
- **多窗口共享**：同一编辑器安装实例共享一个本机代理进程；编辑器运行期间由扩展心跳保活，窗口全部关闭或扩展停用后，代理在十分钟无请求时自动退出，下次使用会自动拉起。

## 快速开始

### 1. 安装

要求 VS Code `1.107.0` 或更高版本（Trae CN 3.4 及以后的版本满足要求）。用量数据库使用编辑器内置 Node.js 22 的 `node:sqlite`，无需额外的原生依赖。

从源码构建：

```bash
npm ci
npm run check
npm test
npm run package
```

然后在编辑器的扩展面板中选择“从 VSIX 安装”，安装生成的 `deepseek-token-meter-1.2.2.vsix`。

### 2. 启动本机代理

安装后代理默认随编辑器启动。也可以执行命令面板中的：

- `DeepSeek 本机用量：启动本地代理`
- `DeepSeek 本机用量：停止本地代理`
- `DeepSeek 本机用量：打开统计面板`

状态栏会显示今日 Token 总量和代理运行状态；点击状态栏可打开面板。

### 3. 在 Trae 中接入

打开统计面板的“接入设置”，按以下方式添加自定义模型：

| 字段 | 填写内容 |
| --- | --- |
| API 格式 | OpenAI Chat Completions 格式 |
| 基础地址 | `http://127.0.0.1:18765/v1` |
| 完整 URL | 关闭 |
| 模型 ID | DeepSeek 平台实际支持的模型 ID |
| API 密钥 | 你自己的 DeepSeek API Key |

如果开启“完整 URL”，请填写 `http://127.0.0.1:18765/v1/chat/completions`。

代理只把请求转发给上游，API Key 由你的客户端随请求发送，插件不会把它写入磁盘。连通性测试也是一次真实调用，会被计入用量。

### 4. 配置单价

新安装默认使用 `deepseek-flash` 的高峰时段单价（见下表），可按实际模型和服务商调价随时修改：

| 模型 ID | 非缓存输入（高峰） | 输出（高峰） | 缓存读取（高峰） | 缓存写入（高峰） |
| --- | --- | --- | --- | --- |
| `deepseek-flash` | 2 | 8 | 0.04 | 0 |

在“模型定价”中为模型填写人民币 / 百万 Tokens 的**高峰单价**：

- 非缓存输入价格
- 输出价格
- 缓存读取价格
- 缓存写入价格

空闲时段单价无需另填，自动取高峰单价的 50%。

模型 ID 支持末尾 `*` 的系列匹配，例如 `deepseek-*`。优先匹配上游实际返回的模型 ID，其次匹配请求中填写的模型 ID，最后按最具体的通配符匹配。`0` 表示该项免费。

费用公式：

```text
费用 =（非缓存输入 × 时段单价 + 缓存读取 × 时段单价
      + 缓存写入 × 时段单价 + 输出 × 时段单价）÷ 1,000,000

时段单价 = 高峰单价（高峰时段）或 高峰单价 × 50%（空闲时段）
```

高峰时段按**北京时间**判断：周一至周五 `09:00–12:00`、`14:00–18:00`，中国法定节假日除外；其余时段以及周末、法定节假日全天均为空闲。峰谷以每条请求的 `startedAt`（请求开始时间）为准。调休上班的周末按工作日处理。

如果节假日数据暂时无法获取，或实际放假、调休安排与数据源不一致，可在“模型定价”中开启“手动兜底：忽略法定节假日与调休，仅按周一至周五的工作时间判断”。开启后历史记录也会按新规则重新计算高峰 / 空闲归属。

这是按当前单价计算的估算值，不代表服务商的实际扣费账单。

## 统计口径

- 只统计请求经过本机代理的模型生成调用；`/v1/models` 查询不计入。
- 按请求开始时间和配置的时区（默认 `Asia/Shanghai`）归属自然日。
- DeepSeek 的 `prompt_tokens` 已包含缓存命中部分，`completion_tokens` 已包含推理 Tokens。插件会拆分缓存读取/写入，避免重复累计；推理 Tokens 只作为输出中的明细展示，不再额外相加。
- 成功、异常、取消分别统计。HTTP 错误、上游中断、客户端取消和缺少 usage 的请求都有独立标记。
- 没有收到 usage 的请求会记录为“用量未知”，不按 0 费用计入；中断请求可能只收到部分 usage。
- 支持解析 DeepSeek / OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 风格的 usage 字段，并对 gzip / deflate / br 响应解码后统计。
- 每条记录都保存完整的请求开始时间（`startedAt`，ISO 8601）。峰谷判断固定使用北京时间，与面板展示时区无关；因此修改时区只影响按日归集，不会改变峰谷归属。
- 中国法定节假日与调休数据来自 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 公开数据（依据国务院办公厅通知整理）。插件启动时请求当年与次年数据并写入数据目录缓存；网络不可用时沿用本地缓存，尚未获取到数据时只按周末与工作时间判断。

## 数据与隐私

数据目录由编辑器分配，可在面板“本地数据”中查看并打开，通常位于全局存储目录下的 `local-tools.deepseek-token-meter`：

```text
usage.db              SQLite 数据库（用量记录；运行时可能有 -wal / -shm 文件）
config.json           上游地址、时区、模型高峰单价
holidays.json         法定节假日与调休缓存（启动时自动刷新）
holidays.lock         多窗口刷新节假日数据时的短时文件锁
admin-token           本机管理接口令牌
```

从旧版本升级时，首次启动会把已有的 `events/YYYY-MM.jsonl` 在一个事务内导入 `usage.db`，按记录 ID 去重；导入提交成功后删除旧 JSONL 文件，无法解析的行会跳过并在面板提示。之后所有统计与导出都直接查询 SQLite，不再把全部历史记录读入内存。

- 用量记录只包含模型、时间、Token、状态、HTTP 状态、耗时、错误码，以及请求体中的显式标题字段（如 `title` / `name` / `metadata.title`）和结构化摘要（消息条数、工具数、是否流式、max tokens）；不保存 API Key、对话、提示词或响应正文。
- 只保留最近 365 天的记录，插件或代理每次启动时会删除更早的数据，并执行 `PRAGMA incremental_vacuum` 与 `PRAGMA optimize`，把删除后的空闲页归还磁盘，避免数据库文件只增不减。
- 面板“清空数据”需要再次输入“清空”确认，只删除用量记录，保留模型单价、上游地址、时区与节假日缓存；清空后不可撤销。
- 代理仅监听 `127.0.0.1`，拒绝带 `Origin` 的浏览器请求和非本机 Host。
- 管理接口需要随机令牌；令牌文件以仅当前用户可读写的方式创建。
- 代理不会启动浏览器，也不会把端口暴露到局域网。
- 卸载插件不会自动删除历史用量；需要清理时可直接打开数据目录操作。

## 常见问题

**端口被占用 / 提示“已被其他程序占用”**

修改设置 `deepseekTokenMeter.port`，重新加载窗口后启动代理。不要与其他服务共用端口。

**Trae 返回 401 或提示填写 API Key**

代理不替你保存密钥。请在 Trae 的自定义模型配置中填写有效的 DeepSeek API Key。

**面板没有新数据**

确认代理正在运行、Trae 的基础地址指向 `http://127.0.0.1:18765/v1`、且没有开启“完整 URL”，然后发起一次模型对话。连通性测试也会计入用量。

**费用显示“未定价”或“—”**

在“模型定价”中为对应模型配置四项单价并保存。没有 usage 的请求无法估算费用，会显示为未知。

**流式请求没有 usage**

DeepSeek 官方接口通常会在流末尾返回 usage。如果使用兼容中转服务，可在设置中开启“为流式请求补充 `stream_options.include_usage`”。

**CSV 导出和“清空数据”分别有什么用？**

- **CSV** 是给人看或做报表的汇总：按自然日和模型聚合 Token、请求次数与费用，只包含当前面板选择的时间范围和模型筛选，不包含单条请求明细，也不能用于恢复数据。需要长期留档时，可在清空前导出 CSV。
- **清空数据** 用来彻底删除本机全部用量记录，只保留单价与接入设置，适合共享电脑前清理或重新开始统计；需要输入“清空”二次确认，且不可撤销。本版本不提供 JSON 备份或导入功能；如需保留原始数据库，可在关闭编辑器后手动复制数据目录中的 `usage.db`。

**节假日刷新失败或调休不一致**

节假日数据只需要联网成功获取一次。若启动时无法联网，会沿用 `holidays.json` 缓存；如果缓存也没有，或你希望完全不考虑法定节假日与调休，可在“模型定价”中开启“手动兜底”，此时只按周一至周五的工作时间判断高峰。

**代理空闲后停止**

编辑器窗口全部关闭或扩展停用后，代理在十分钟无请求时自动退出，这是正常行为；再次打开编辑器或执行“启动本地代理”命令会自动拉起。

## 限制

- 只记录经过本机代理的请求。Trae 内置云端模型、其他电脑、直接在别处调用官方 API 的请求不会自动出现。
- 费用是估算，不替代服务商账单；单价需要手动维护。
- 法定节假日与调休数据需要联网刷新一次；离线时沿用上次缓存，首次离线安装只按周末与工作时间判断峰谷。
- 仅面向本机单用户，不提供局域网共享、账号体系或云端同步。
- 代理支持常见的 OpenAI / Anthropic 兼容接口路径；其他接口会返回 404 提示。
