Token 定价

为不同模型设置单价，单位：人民币 / 百万 Tokens。

表内填写高峰时段单价，空闲时段自动按 50% 计算。高峰：北京时间周一至周五 09:00–12:00、14:00–18:00（中国法定节假日除外）；其余时段、周末与节假日全天为空闲。非缓存输入、缓存读取、缓存写入与输出独立计价，推理 Token 已包含在输出中。
模型单价CNY / 1M TOKENS
模型 ID输入价格（高峰）输出价格（高峰）缓存读取价格（高峰）缓存写入价格（高峰）

可用末尾 * 匹配模型系列，例如 deepseek-*。优先匹配实际返回的模型 ID，其次匹配请求的模型 ID。空闲时段单价 = 高峰单价 × 50%，无需单独填写。未设置单价的模型仍统计 Token，费用显示为“未定价”。

人民币估算规则

费用 =（非缓存输入 × 时段单价 + 缓存读取 × 时段单价 + 缓存写入 × 时段单价 + 输出 × 时段单价）÷ 1,000,000；高峰时段用表内单价，空闲时段按 50%。

调整单价后，历史记录也会按当前单价重新估算。新安装默认使用 deepseek-flash 的高峰时段单价（输入 2、输出 8、缓存读取 0.04、缓存写入 0 元 / 百万 Tokens），可按实际模型调整；0 表示该项免费。

接入 DeepSeek

把自定义模型接到本机代理，保留 Trae 原有的对话和工具调用。

1

复制本机请求地址

http://127.0.0.1:18765/v1

Trae → 设置 → 模型 → 添加模型 → 自定义模型

2

填写 Trae 自定义模型

API 格式
OpenAI Chat Completions 格式
完整 URL
关闭，基础地址粘贴上方地址
模型 ID
填写 DeepSeek 平台支持的实际模型 ID
API 密钥
填写你自己的 DeepSeek API Key

如果开启“完整 URL”，请使用 http://127.0.0.1:18765/v1/chat/completions

3

配置单价并发起对话

在“模型定价”中设置人民币单价，完成 Trae 连通性测试后开始使用。连通性测试也是真实调用，会计入本机用量。

只统计经过该地址的请求。Trae 内置云端模型、其他电脑及直接调用官方地址的请求不会被自动记录。历史用量可导入本插件的备份。

代理设置

默认直连 DeepSeek 官方 API。可填写兼容服务的基础地址，例如 https://example.com/v1；不要填写 /chat/completions，不在地址中放密钥。

每日统计按此时区划分，默认北京时间；改变时区会重新汇总历史记录。

DeepSeek 官方接口本身会返回最终 usage，默认关闭。仅在兼容中转服务需要此参数时开启。

本地数据

独立于当前项目

仅保存模型、时间、Token、状态和耗时，不保存 API Key、对话或响应正文。导入按记录 ID 去重，不覆盖当前单价；多个编辑器窗口共享同一个本机代理。
